# ADR-0017：地图按城市聚合（城市标记）

- 状态：已接受
- 日期：2026-09-10
- 决策人：agent + 用户（“同一个城市的话，在地图只显示一个 icon，点击后再显示多次记录”）

## 背景

1. **现状**：地图把「同坐标（WGS-84 4 位小数 ≈11 米）」的记录合并成一枚标注（ADR-0004）。同一个城市里的不同地点因此各出一枚标注——一个城市散成好几个点，与用户“一个城市一个图标”的诉求相反。
2. **已有相邻概念**：时光轴已按 City 折叠，但语义是「**相邻**同城」（City run，ADR-0015）；它解决的是时间轴上的分段，不是地图上的聚合。
3. **数据现实**（本地库实测）：有 City 的记录几乎**每条坐标都不同**（上海 3 条 = 3 个坐标、中山 3 = 3、广州 2 = 2）。所以城市标记没有“天然的那个坐标”，锚点必须显式定义。
4. **City 是快照且可能为空**：City 在写入时由逆地理结果落成快照（ADR-0015），历史数据里有大量 `City = NULL`，需要回退路径。

## 决策

1. **两级口径，城市优先**：有 City 快照的记录按城市合成**城市标记**（`groupMapMarkers()` 的 `kind: 'city'`）；City 为空的记录保留 ADR-0004 的按坐标合并（`kind: 'place'`）。两类独立渲染，极端重合时允许叠在一起。
2. **一城一标，取代坐标聚合**：不保留“城市内再按坐标分层”。城市标记的锚点 = 该城全部记录的**质心**（WGS-84，渲染前转 GCJ-02）。
3. **点开才展开**：点击城市标记的信息窗以城市名为标题，副标题写明「N 次停留 · 该城市；标记在该城各次停留的中心」，逐行列出该城记录（最新在前，含地点名、时间区间、进行中徽标、★）。点某一行 → 地图落到**该次停留自己的坐标**并打高亮光圈（`.tm-focus-ring`），同时侧栏高亮该条。地点标记的信息窗维持原样。
4. **图标**：城市标记优先用该城的**地区特色图标**（`regionalIconKey(city)`，ADR-0016；城市一致 ⇒ 派生必然一致）；该城未收录映射时回退“组内解析一致的图标”，再回退默认标记（熊猫）+ 计数。
5. **配色收敛为两档**：组内有进行中记录 → 绿，否则 → 橙。**多次不再用紫色**（`tm-marker--merged` 删除）：次数由右上角计数徽标 `N` 表达（N > 1），该组含精选收藏时左上角加 `★`（ADR-0014）。图例同步为“普通停留 / 进行中 / ★ 精选收藏 / 停留次数 + 一行说明”。
6. **层级**：城市标记的 `zIndex` 高于地点标记（质心可能恰好压在无 City 的旧记录上，聚合口径优先可点）；进行中的标记再抬一档。
7. **不随缩放拆分**：即使放大到街道级，城市标记也不拆成各记录的点；要看具体位置就点信息窗里的某一行（高亮光圈）。将来若确有需要，再做成可选开关。
8. **时光轴口径不动**：City run 保持「相邻同城」的时间连续语义，与地图的「全城一标」并存。两者粒度差异是刻意的，不是遗漏。

## 影响

- 前端：`utils/travel-display.ts` 的 `groupRecords` / `TravelMarkerGroup` → `groupMapMarkers` / `MapMarkerGroup`（新增 `kind` / `city`，**组内与组间都按到达时间倒序排序**，不再依赖入参顺序）；`map-page` 的渲染、信息窗、定位联动随之调整；`styles.scss` 新增 `.tm-marker__star`、`.tm-focus-ring`，删除紫色态；地图图例改写。
- 后端 / API：无变化（`City` 早已在 DTO 里）。
- 语义：地图上的标记数量从“每条记录的坐标数”变为“每城一个 + 无 City 的坐标数”，与侧栏分页列表（仍按到达时间分页）**不必一一对应**——页面只渲染当前页加载到的记录所对应的标记。
- ADR-0004：被**部分取代**——同坐标合并现在只服务 City 为空的记录。
- ADR-0015 / ADR-0016：口径不变，仅补齐“地图这一侧如何用 City 与图标”的规则。

## 备选

- **城市内再分层**（城市 → 坐标 → 记录）：点击链路变长，与“一个城市一个图标”的诉求冲突，否决。
- **锚点用“最新一次到访的坐标”**：标记会随最近一次到访在地图上来回跳，否决。
- **锚点用“最常去的那个坐标”**：只有 1 条记录时退化成上一条，且“最常去”对用户不可见，否决。
- **缩放时把城市标记拆成各记录的点**：同一屏里标记语义随缩放变化，容易误读，否决（保留为将来的可选开关）。
- **点击城市标记后把视野放大到城市范围**：信息量低于“落到具体某次停留”，且与「回到全览」按钮职责重叠，否决。
- **给无 City 的旧记录补做逆地理再按城聚合**：20 万条记录的反查成本高、引入外部依赖与历史数据写入，否决。
- **城市标记改用独立形状（如描边圆圈）以区别地点标记**：一屏内两套视觉语言、且与 ADR-0011/0016 的配色语义打架，否决；改用计数徽标 + 图例说明区分。

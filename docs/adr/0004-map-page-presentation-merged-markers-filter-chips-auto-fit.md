# Map page presentation: merged same-spot markers, arrival-window filter chips, auto-fit viewport

`/map` 展示层收敛规则（Angular 22 zoneless + signals，只读，无录入）：

- **同一地点多次停留 → 同坐标合并标注**：单用户记录量通常 <100，不做聚合插件；把坐标近似相等（容差内，按 4 位小数分组）的多条记录折叠为一枚标注，点击弹出该点全部停留明细；列表/气泡行可高亮联动。单条记录仍对应地图一个点（与 ADR-0001 一致），合并仅是视觉折叠。
  （**部分被 ADR-0017 取代**：有 City 快照的记录现在按城市合成「城市标记」；同坐标合并只服务 City 为空的记录。）
- **侧边时间线列表**：按 `arrivedAt` 倒序；提供筛选 chips（全部 / 近30天 / 今年 / 自定义起止）。自定义走原生日期输入。筛选一律映射为后端 `from/to`（到达时间窗，UTC 时刻）**服务端过滤**后重新拉取，不把"已过滤列表"留在客户端拼假。
- **默认视野**：进入页面、切换用户、筛选变化后 `setFitView` 自动适配当前标注集合（带 padding）；无标注时显示空态 + 全国默认视野；提供手动"回到全览"。不做视野记忆（localStorage 只存上次选中的 userId）。
- **地图数据范围可切换**（后续补充，「跟随列表 / 全部足迹」两段式开关）：地图默认**跟随列表**——只画侧栏**当前页**的记录（与筛选/分页一致，即原行为）；切到**全部足迹**——忽略时间筛选、★ 收藏筛选与分页，画该用户的全部停留（上限 1000 条，超出时提示"仅显示最近 1000 条"）。两个模式**只影响地图**：侧栏列表仍分页、时光轴仍是当前范围。「跟随列表」不需要额外数据，因此加载全量期间可以直接切回。切换后自动回到全览（因此"筛选变化后自动适配视野"只适用于跟随列表模式）；切换保留已选中记录但关闭气泡。开关与「分享足迹」「回到全览」都放在地图**外面**（地图上方的工具条；分享仍分享侧栏当前页，回到全览在没有标记时禁用）。
- **进行中停留**（`departedAt == null`）在标注与列表中视觉区分；其余展示约定（WGS-84 存储、GCJ-02 转换、AMap JSAPI 2.0 动态加载、密钥占位）见 ADR-0003。
- **标记随缩放分三级**（后续补充，"远 / 中 / 近"档标准）：

  | 档位 | zoom（含端点） | 视野观感 | 标记 | 计数 / ★ 徽标 |
  | ---- | -------------- | -------- | ---- | ------------- |
  | 远   | 3–7            | 全国 / 省域 | 28px | 16px |
  | 中   | 8–12           | 城市 / 区县 | 42px | 18px |
  | 近   | 13–20          | 街区        | 56px | 22px |

  规则与理由：
  - **按 zoom 固定分档**，不按"当前可见标记数量 / 重叠程度"自适应：固定分档可预测、不抖动，不会因为数据刷新而改变同一视野下的观感。
  - 尺寸比固定 **1 : 1.5 : 2**（缩放因子 2/3、1、4/3），边界取 7|8、12|13 对应高德地图"省域 / 城市区县 / 街区"的观感切换。**中档 42px 就是改造前的固定尺寸**，应用自身的定位缩放（`FOCUS_ZOOM = 10`、`TIMELINE_FOCUS_ZOOM = 12`）都落在中档，所以从侧栏或时光轴定位过去的观感与历史行为一致。
  - **徽标不与标记同比例缩放**：同比例在远档只有 12px、数字读不出来，因此三档徽标尺寸独立给出（16 / 18 / 22）。
  - **标记外框固定 42px，只有"画面层"缩放**：视觉随档位变化，但**点击热区在任何档位都不小于 42px**（远档视觉 28px 时仍可点到），避免"看得到点不到"；近档视觉 56px 大于外框，标记自身不做裁剪（舞台边界仍按既有的 `.map-stage { overflow: hidden }` 裁剪），因此视觉范围内处处可点。
  - **只在 `zoomend` 重算一次**（外加初始化一次）：连续缩放中不改样式；档位变化只换 `.map-stage` 上的两个 CSS 自定义属性（`--marker-scale`、`--badge-scale`），**不重建标记**——重建会关闭信息窗并抢走视野（见"筛选变化后自动适配视野"的既有约束）。当前档位同时以 `data-zoom-tier` 暴露在 `.map-stage` 上，作为调试与 E2E 断言的钩子（样式不依赖它）。
  - 分档标准（边界 + 三档尺寸）只有一份定义：`src/frontend/client/src/app/features/travel/utils/map-zoom.util.ts` 的 `MARKER_TIERS`，CSS 只消费它输出的变量；两个基准尺寸（标记 42px、徽标 18px）也定义在同一文件的 `MARKER_BASE_SIZE` / `BADGE_BASE_SIZE`，`styles.scss` 里对应的硬编码值均有注释指向它们。`markerTierFor` 按档位**起点**（`minZoom`）从近到远查找，因此 `setFitView` 产出的**小数 zoom**（如 7.5 / 12.4）落在表格空隙时归到较低的一档，不会错落到远档；越界值钳制到首 / 末档，异常值（`NaN`）回退中档。
  - **不做设备分叉**（移动端同一套标准，只靠 42px 固定热区保证可点）；不给用户提示"标记随缩放变化"（地图的常规行为，写出来反而占位）。
  - 「定位到某次停留」的高亮光圈与信息窗**不随档位缩放**（它们是定位反馈与内容层，尺寸稳定更易读）。
